# DaVinci Director

Монтаж через текст для DaVinci Resolve 21.1.2+ (Free і Studio), Windows.

Правки в тексті змінюють кліпи на таймлайні Resolve, правки в Resolve змінюють текст. Плюс транскрибування з мовцями і пошук сюжетів через мовну модель (запит копіюється в чат, відповідь імпортується).

## Встановлення

Інсталятор `DaVinciDirector-Setup-<версія>.exe` (див. «Збірка»). Компоненти й модель розпізнавання (≈ 3–6 ГБ) програма завантажує сама під час першої транскрипції.

Запуск: у Resolve **Workspace > Scripts > DaVinci Director**. Після кожного перезапуску Resolve — знову через меню.

## Використання

- **Транскрибувати** — розпізнає мову на вибраній доріжці (Parakeet TDT 0.6B v3 UK). Для визначення мовців потрібен токен Hugging Face типу Read і прийняті умови на https://hf.co/pyannote/speaker-diarization-community-1.
- **Текст** — слова в кольорі мовця, паузи від 3 с позначені, тиша від 6 с окремим рядком.

| Дія | Як |
|---|---|
| Виділити | мишею по словах, `Shift`+клік, `Shift`+стрілки; 2×клік — речення, 3×клік — абзац |
| Програти виділене в Resolve | `Space` |
| Вирізати / повернути вирізане | `Del` |
| Перенести / копіювати | тягнути виділене (з `Ctrl` — копія); `Ctrl+C`, `Ctrl+V`, `Ctrl+D` |
| Змінити мовця | `1`–`9` або кнопка мовця на панелі виділення |
| Виправити текст | `F2` (відео не змінюється) |
| Скасувати / повторити | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Пошук | `Ctrl+F` |

- **Експорт** — запит для мовної моделі: тривалість, кількість варіантів, побажання. Довгі записи — у два етапи. **Імпорт** — вставити відповідь; варіанти з'являються на вкладці «Сюжети» і застосовуються новим таймлайном або замість поточного монтажу.

## Обмеження

- Розрізання кліпа не переносить ефекти, грейд і швидкість на другу половину — монтуйте текстом до кольорокорекції.
- Ripple зсуває лише редаговану доріжку і пов'язане аудіо.
- Швидкість кліпів — тільки 100%.
- «Програти» натискає Space у вікні Resolve: API Resolve не має команди відтворення.

## Збірка

```powershell
.venv\Scripts\python build.py
```

Результат — `dist\DaVinciDirector-Setup-<версія>.exe`. Для розробки: `python install.py` (`--uninstall` — прибрати).
